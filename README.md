# Secret Santa

Web app to organise gift exchanges in groups: create a group, accept join requests, run a fair draw where each member only sees who they give to, and rate the gift you received anonymously.

Built with React 19, Material UI 9, Redux Toolkit, Firebase 13 (Auth + Firestore) and Vite 8.

## Quick path

1. Install Node `^20.19` or `>=22.12`, then `npm install`.
2. `npm run dev` and open <http://localhost:3000>.
3. `npm test` should pass before any change is pushed.

## Scripts

| Script | What it does |
|--------|--------------|
| `npm run dev` | Development server on port 3000 |
| `npm run build` | Production build into `dist/` (served by Firebase Hosting) |
| `npm run preview` | Serves the production build locally |
| `npm test` | Unit and component tests (Vitest + Testing Library) |
| `npm run lint` | ESLint, including the React hooks rules |
| `npm run test:rules` | Firestore security rules tests against the emulator (needs Java and `firebase-tools`) |

## Data model

| Path | Content | Who can read it |
|------|---------|-----------------|
| `users/{uid}` | `{ name, email }` | Signed-in users (by id) |
| `groups/{groupId}` | Name, admin, members, requests, draw stage, rating aggregate | Signed-in users |
| `groupNames/{nameId}` | `{ groupId }`: keeps names unique ignoring case and extra spaces | Signed-in users |
| `groups/{groupId}/assignments/{uid}` | Who `uid` gives a present to | Only `uid` |
| `groups/{groupId}/wishes/{uid}` | What `uid` would like to receive | Group members |
| `groups/{groupId}/ratings/{uid}` | The rating `uid` gave to their present | Only `uid` |

Group ids are generated by Firestore; the group name is a normal field. Every multi-document change (create, delete, draw, reset, leave) is a single batch or transaction, and `firestore.rules` only allows those exact operations.

## Deploy

```bash
npm run build
firebase deploy --only hosting,firestore:rules
```

Run `npm run test:rules` before deploying rule changes.

## Known limitations

- The draw is computed in the admin's browser, so a technical admin could inspect it while it is generated. Hiding it completely requires a Cloud Function.
- Group search downloads every group name; fine for a small app, not for thousands of groups.
